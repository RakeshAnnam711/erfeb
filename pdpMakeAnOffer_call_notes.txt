Purpose
-------
This content asset renders the PDP "Make an Offer" modal and submits offer data
to Salesforce using Web-to-Case.

Why this change was made:
Previously the Salesforce field ids were hardcoded directly on each input.
Now each environment can update one config block instead of searching through
the full HTML form.


How config is applied
---------------------
Lines 229-242 define applySalesforceWebToCaseConfig().

This function applies the config to the form:

- Line 232:
  Sets the form action URL.

- Lines 233-234:
  Sets orgid field name and org id value.

- Lines 235-241:
  Sets the Salesforce name attributes for SKU, contact name, first name,
  last name, email, phone, and offer amount.

Line 252 calls applySalesforceWebToCaseConfig() before setting field values or
submitting the form.

JavaScript flow
---------------

- Reads PDP values:

  - product price
  - product SKU
  - sentOffer query param
  - offer input
  - retail price input

Line 252:
- Applies Salesforce config to the form.

Line 253:
- Sets SKU hidden field value.

Lines 255-257:
- Shows "Offer Sent" if URL has sentOffer=true.

  - offer must not be more than retail
- Disables submit button if invalid.

Lines 290-346:

- Prevents native submit.
- Reads first name, last name, phone, email, and converted offer amount.

- Line 302 sets standard contact name:

- Validates first name, last name, phone, and email.
- If valid:
  - Line 331 sets offer input to converted USD value.
  - Line 332 submits the Web-to-Case form.
  - Lines 334-339 show "Offer Sent".
  - Lines 341-344 notify parent PDP script using CustomerOfferSent.
